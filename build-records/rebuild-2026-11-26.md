# Rebuild the Arduino firmware

The published set covers the 15 CoreS3 and 11 Cardputer-Adv Arduino cases in the native esp32sim matrix. Each manifest links the original build hashes and the validation of the rebuilt merged image. Archived sketches and board defaults match the original builds.

## Rebuild command

Run from the archive root with Arduino CLI 1.3.1 and Python 3.11+. The recorded build used macOS arm64. These setup commands create an isolated Arduino install. Use a path without spaces for the install and build directories because the board package uses shell recipes.

```bash
cli="$(command -v arduino-cli)"
install="$(mktemp -d)"
export ARDUINO_DIRECTORIES_DATA="$install/data"
export ARDUINO_DIRECTORIES_DOWNLOADS="$install/downloads"
export ARDUINO_DIRECTORIES_USER="$install/user"
config="$install/arduino-cli.yaml"
cat >"$config" <<'YAML'
board_manager:
  additional_urls:
    - https://static-cdn.m5stack.com/resource/arduino/package_m5stack_index.json
YAML
"$cli" --config-file "$config" core update-index
"$cli" --config-file "$config" core install m5stack:esp32@3.2.5
libs="$ARDUINO_DIRECTORIES_USER/libraries"
mkdir -p "$libs"
pin() {
    git clone --no-checkout "$1" "$libs/$2" &&
        git -C "$libs/$2" checkout --detach "$3"
}
pin https://github.com/m5stack/M5Unified.git M5Unified 96576a14247ddc935149145aa6b51943464120f1
pin https://github.com/m5stack/M5GFX.git M5GFX 28d47949bdc84f30881623476f555398e2194313
pin https://github.com/m5stack/M5Cardputer.git M5Cardputer 2d4fa6646e4e5b47e0af96214b003aa7b15b8d81
pin https://github.com/Arduino-IRremote/Arduino-IRremote.git Arduino-IRremote 498dc591b255d8ba2e239c875804bdab2ab0fe91
python3 -m venv "$install/esptool"
"$install/esptool/bin/python" -m pip install 'esptool==5.0.dev1'
ln -s esptool.py "$install/esptool/bin/esptool"

python3 tools/rebuild_arduino.py --cli "$cli" --config "$config" \
    --data "$ARDUINO_DIRECTORIES_DATA" --user "$ARDUINO_DIRECTORIES_USER" \
    --esptool-dir "$install/esptool/bin" --out "$install/rebuild" --jobs 4 --compiler-jobs 3
python3 tools/verify.py --rebuilt-dir "$install/rebuild/firmware"
python3 tools/scan_firmware_paths.py "$install/rebuild/firmware"
```

The builder sets `SOURCE_DATE_EPOCH=1795651200` and `TZ=UTC`. It applies
`-ffile-prefix-map`, `-fdebug-prefix-map`, and `-fmacro-prefix-map`
to each pair in the table, via `compiler.c.extra_flags`, `compiler.cpp.extra_flags`,
and `compiler.S.extra_flags`.

| Canonical input path | Replacement |
| --- | --- |
| `--data` (board package, SDK and toolchain) | `/build-env/arduino-data` |
| `--user` (libraries) | `/build-env/arduino-user` |
| `--out` (sketches and build outputs) | `/build-env/work` |

The FQBNs are `m5stack:esp32:m5stack_cores3` and `m5stack:esp32:m5stack_cardputer`.
The build uses the 3.2.5 board defaults, with 16 MiB and 4 MiB merged images respectively.
The path scanner reports the remaining Espressif CI/toolchain prefixes.
